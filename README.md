# Neon Bastion for Android

Signed releases of the Neon Bastion Android app. The installed app checks this repository on launch and installs a newer build over the one you have.

Download the latest APK from [Releases](https://github.com/psteen-coder/neon-bastion-android/releases). The first install that replaces an older debug build needs one uninstall, because the signing certificate changed. After that, updates install in place.
